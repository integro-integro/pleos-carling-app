# 마이카링 구현 명세 (MVP PRD v0.1 기준, 2026-11-12)

한 문장: **매일의 운행이 트립카드로 남고, 완성한 카드가 카링의 성장·개성과 운행 리포트로 돌아온다.**
정본 순서: 공모전 양식 > PRD v0.1 제안값 > 이 문서의 구현 제안값.
카링월드(방·집 꾸미기, 아이템 72종, 계열 진화, 카링월드 지도, 퀘스트)는 2026-11-12 사용자 지시로 모두 지웠다(커밋 `7fe56ac`까지에 남아 있다).

## 루프

1. 탑승(P): 홈에서 카링이 인사한다. 확정 후 임시로 남은 카드가 있으면 재안내 시트가 먼저 뜬다.
2. 출발(D): 기록이 자동으로 시작되고 홈이 주행 화면으로 바뀐다. 달리는 카링 그림과 거리·시간만, 터치 요소 없음.
3. 주차(P): 임시 카드 시트가 바로 뜬다. 운행 목적 하나를 고르고 '완성하기'(또는 '나중에').
4. 보상: 운행 확정(P 5분 유지) + 카드 완성이 모두 참이 되는 순간 성장 포인트와 럭키박스 1개가 한 번 지급된다.
5. 변화 확인: 단계가 오르면 연출, 개성이 바뀌면 근거 한 줄과 함께 알림.
6. 리포트: 주차 중 하단 '리포트' 탭.

## 화면 (`ui/`)

- **홈 P (`HomeScreen.kt`)**: Pleos 느낌의 라벤더 블루 배경(`Backdrop.kt`, 지평선 두 겹과 빛나는 선, 시간대마다 하늘색이 바뀌고 빛 덩어리가 60초 주기로 천천히 흐름, 밤엔 별). 차에 탄 카링, 말풍선 한 줄, "P · 함께 출발해요", 하단 탭(카링·트립카드·리포트), 임시 카드 배지, 럭키박스 버튼. 오른쪽에 단계·성장 바·개성 3축과 근거·자동차 꾸미기(눌러서 붙이기/떼기)·수집 배지.
- **홈 D (`CarlingApp.kt`)**: 같은 배경(정지), 달리는 카링 그림, "D 함께 달리는 중 · 거리 · 분". 움직임·터치 없음.
- **트립카드 (`TripCards.kt`, `CardArt.kt`, 시안 v1 2026-11-12)**: 위는 목적 풍경(출퇴근 도시 스카이라인·외근 업무 지구와 고가도로·가족과 함께 텐트와 모닥불·여행 설산과 호수·취미 벚꽃길·기타 민트 길)과 출발 시간대 하늘(아침·낮·저녁·밤, 밤엔 별과 불빛). 코드로 그린 원본 그림이고 카드마다 배치가 조금씩 다르다. 목적을 고르기 전엔 하늘만 보이고 고르는 순간 풍경이 담긴다. 아래는 목적 칩·날짜와 시각·거리·이동(경과)시간·운전점수와 보상 상태. 등급(**구현 제안**): 반짝=운전점수 85+ 민트 무지갯빛 테두리, 특별=첫 카드 또는 100km 이상 금빛 테두리와 SPECIAL 리본, 보상량은 같다. 도착 시트는 뒷면이 떨어져 뒤집히고 빛이 지나가며 반짝이가 퍼지는 연출(약 2초)과 함께 열리고, 제목이 등급에 따라 바뀐다. 시트는 목적 칩 6개(큰 버튼) + 완성하기. 목록은 최신순, 상태 필터, 임시 카드 모두 완성(추천 목적, 없으면 기타). 완성 카드는 목적 고치기(개성 재계산).
- **리포트 (`ReportScreen.kt`, `game/Report.kt`)**: 이번 달·지난 달·최근 7일. ① 핵심 발견 최대 3문장 + 다음에 살펴볼 일(PRD 4.6 규칙, 생성형 AI 미사용, 3회 미만이면 안내 문구) ② 운행 현황 4개와 직전 기간 대비 증감 ② 날마다 달린 거리 막대(주중/주말 색) ③ 목적별 횟수·거리·시간·비중 막대, 미분류는 미완성·만료·기준 미달로 나눠 표시 ④ 생활 패턴: 시간대 분포, 주중/주말, 단·중·장거리(10km 미만·30km 이상), 운전일 하루 평균, 평균 운전점수 ⑤ 카링 성장 내역: 완성 카드 수, 획득 포인트, 단계 변화, 지금의 개성과 근거.
- **럭키박스 (`LuckyBox.kt`)**: 상자 1탭 개봉(뚜껑·빛줄기 연출 약 1초), 보상 2줄, 여러 개면 '다음 상자'.
- **카링 그림 (`KaringArt.kt`)**: 사용자 전달 원본 10장. 단계마다 서 있기·차(주차)·달리기 세 장. 그림이 층으로 나뉘어 있지 않아 몸 색은 카링 뒤 빛무리로, 장식과 자동차 아이템은 그림 위에 얹는 아이콘으로 표현한다. 서 있는 카링은 누르면 말랑하게 출렁인다.
- **동의 (`ConsentDialog`)**: 기록하는 것(기어·속도·주행거리·목적/태그)과 하지 않는 것(위치·경로) 안내 후 동의.
- **시뮬레이터 (debug)**: 지금 주차한 운행, 짧은 운행, 5분/24시간/7일 지나기, 다시 시동, 아침 출퇴근 9장, 밤 외근 6장, 주말 가족 3장, 포인트 +1,000, 초기화.

## 데이터 (`data/CarlingData.kt`)

TripRecord(모든 운행) · TripCard(운행당 최대 1장) · rewards(보상 원장) · LuckyBox · PersonalitySnapshot(개성 변화 근거) · StageChange · badges · carItems · events(베타 지표용 로컬 로그). 저장은 SharedPreferences의 JSON 한 덩어리(`mycarling_v1`)이고 상태 전체를 한 번에 바꿔 쓰므로, PRD가 제안한 Room 기본키 제약 대신 원장 키 검사로 1회 지급을 보장한다. 시계(`game/Clock.kt`)와 저장소(`Storage`)는 주입형이라 PRD T1~T10을 `TripFlowTest`로 검증한다.

## 확인이 필요한 것

- **시동 신호:** `IGNITION_STATE`는 아직 쓰지 않는다. 시동을 끄면 앱이 꺼진 것으로 보고 다음 실행 때 소급 판정한다(T3은 T8과 같은 결과). 재안내 기준 '시동'은 앱이 새로 뜨거나 새 운행이 시작된 때다.
- **에뮬레이터 거리:** 주행거리가 변하지 않아 실제 기어 조작 운행은 0.0km로 보인다. debug 빌드는 카드 기준을 낮추고 경과 시간을 이동시간으로 쓴다.
- **그림 층 분리:** 몸 색 틴트는 몸체/얼굴/심장/장식/차량 층 그림이 오면 교체한다.
- **단계 3·4 이름:** 산들카링·마이카링은 구현 제안이다. PRD의 '붕붕 카링'(장난감 차) 그림은 없다.
- **양식과 달라진 점:** 목적 선택 필수('기타' 추가), P 즉시 임시 카드·5분/시동 종료 확정, '저장' = '완성하기', 위치 기능 보류. PRD 8장 표대로 제출 양식 문구 수정이 필요하다.
- **배경 그림:** 지금은 코드로 그린 배경이다. AI 생성 배경 이미지로 바꿀지 사용자 결정 대기.
