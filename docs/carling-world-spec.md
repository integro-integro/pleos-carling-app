# 카링월드 구현 명세 (기획안 v2.2 기준, 2026-11-10)

핵심 문장: **함께 달린 만큼, 우리의 세계가 자란다.**
운전 → 트립카드 → 보상 자동 저장 → 아이템 자동 배치 → 월드 감상 → 성장·진화·공간 개방.

## 구현 범위

- 젤리 알 4단계(Lv1·2·5·9), 아기 카링, 계열 진화 1 다섯 가지. 진화 2~5는 '추후 공개'로만 표시.
- 작은 방 2.5D 고정 장면, 고정 위치 자동 배치, 바닥 가구와 카링의 앞뒤 정렬.
- 침대(수면)·스탠드(점등)·라디오(춤) 근접 반응. 부화 후 자동 이동으로 동작하고 보상은 없다.
- 트립카드 자동 저장, 세션 ID로 중복 처리 방지, 앱 재실행 시 진행 중 운행 복구.
- 주차 후 연출: 카드 → 레벨 → 알의 금 → 새 아이템. 보지 않아도 결과는 저장되어 있다.
- 운행 퀘스트 3종 자동 판정, 한 번에 하나 활성화, 대기열 보관.
- 성장과 진화 화면, 계열 선택.
- 공간 메뉴(Lv10부터): 잠긴 공간은 열리는 레벨 표시, 정원 이후는 '추후 공개'. 카링이 문까지 걸어간 뒤 화면이 바뀐다(알은 바로 이동).
- 확대·축소: 기본은 확대 화면, 축소하면(버튼 또는 두 손가락) 문·계단·아치에 이름표가 보인다. 누르면 카링이 그쪽으로 걸어가 이동한다(갈 곳이 둘이면 고르기 창).
- 가구 누르기: 아이템과 배경 가구(소파·개수대·욕조·책상)를 누르면 카링이 다가가 행동한다. 소파·의자는 앉기, 침대는 누워 자기, TV는 즐거워하기, 커피·차·과일은 맛있다고 하기, 라디오·레코드·오르골은 춤, 조명은 불 켜기, 책은 읽기, 식물은 냄새 맡기. 카링이 혼자 있을 때도 가끔 스스로 한다. 보상은 없다.
- 공간마다 기본 사물: 거실(소파·계단·아치·문), 주방(개수대와 상부장), 화장실(욕조), 작업실(책상). 그 자리에 있던 아이템(개수대·욕조·책상)은 토스터·향초 세트·오르골로 바꿨다.
- 카링월드 지도(하단 '카링월드'): 카링의 집·정원·해변·숲·하늘 전망대·하늘 섬. 지금 있는 집은 빛나고, 열리지 않은 곳은 안개와 자물쇠·필요 진화 단계로 표시.
- 아이템 도감: 공간별 전체·획득 수, 없는 아이템은 실루엣.
- 트립카드: 지난 카드를 모두 저장(안전 한도 3,000장), 오늘·지난 7일·14일·30일·전체 필터.
- 말랑 젤리 몸과 옹알이 목소리(이전 작업 유지). 주행 제한 중 게임 화면 숨김(`CarUxRestrictions` + 기어).

## 결정 사항

- **안전 점수 (2026-11-10 사용자 결정):** 앱이 급조작 수로 계산한 점수를 그대로 쓰고, 90점 이상이면 +5 XP를 준다. 지금 계산식은 급조작 0회 95점, 1회 88점이라 보너스는 급조작 0회 운행에만 붙는다. 차속을 못 받으면 점수는 "미지원"이고 보너스는 없다.

## 지운 기능 (커밋 d79ca24에 보존)

배경 스킨 8종, 안개 지도·경로 기록, 위치 동의, 날씨 인사, 자동차 도감·카링 도감, 머리 장식·탈것·간식,
밥 주기·포만감·쓰다듬기 XP, 차량 돌봄 퀘스트(공기압·연료·오일), 정비 쿠폰, 24시간 저장 기한.

## 확인이 필요한 것

- **실제 이동시간:** 차속 권한(`CAR_SPEED`)이 필요하다. 거부하면 release 빌드는 카드를 만들지 않는다. 에뮬레이터는 속도가 0이라 debug 빌드는 경과 시간으로 대신한다.
- **데이터 누락:** 거리·이동시간을 모르면 카드를 만들지 않는다. 기획안의 '확인 필요' 상태 보관은 아직 없다.
- **운전일:** 시작·종료 날짜를 모두 센다. 자정을 넘긴 운행의 XP는 종료 날짜에 귀속한다.
- **사용자 프로필:** 카링 ID는 저장하지만 Pleos 사용자별 프로필 분리는 아직 없다.
- **그림:** 방·거실·주방·화장실·작업실 배경, 아이템 72종, 문 그림, 카링월드 지도는 사용자 스토리보드를 참고해 AI로 생성했다. 카링·젤리 알은 사용자 전달 원본이다.
- **정원 이후 지역:** 지도에는 보이지만 아직 들어갈 수 없다. 계열 진화 1을 마치면 정원의 안개가 걷히고 "곧 열려요"로 바뀐다.
- **문 일부가 가구에 가림:** 침실 문 아래쪽은 침대 그림과 겹쳐, 그 부분을 누르면 침대 교감이 된다. 문 위쪽이나 이름표를 누르면 된다.
- **계열 진화 4의 레벨:** 진화는 Lv70, 전망대는 Lv77로 서로 다르게 적혀 있어 지금은 둘 다 Lv70으로 표시한다.
- **집 전체 개요 그림:** 계열 진화 1에 열리던 집 전체 화면은 공간 메뉴로 대체해 뺐다.
