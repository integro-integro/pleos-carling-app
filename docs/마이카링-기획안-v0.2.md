# 마이카링 기획안 · PRD v0.2

Nov 13, 2026 · v0.1(11/12 초안)에서 이틀 동안 확정·구현한 내용과 제품 메시지(0장)를 반영

## 0. 카링은 무엇인가

> **달릴수록 나를 알아가는 차 안의 친구.**
> **그냥 흘려보내던 운전 시간을, 돈과 시간을 아끼는 힌트로 돌려준다.**

### 왜 쓰는가

운전은 매일 하는데, 내 운전을 기억하는 건 아무도 없다. 내비게이션은 길만 알려 주고, 차는 연비 숫자 하나를 보여 줄 뿐이다. 출근에 매달 얼마를 쓰는지, 몇 분 일찍 나가면 얼마나 아끼는지, 어떤 날 운전이 거칠어지는지는 아무도 말해 주지 않는다.

카링은 매 운행을 트립카드로 남기고, 쌓인 기록으로 **내가 몰랐던 내 운전**을 알려 준다. 그리고 그 기록으로 자라는 친구가 차 안에 함께 있다.

| 층 | 사용자에게 주는 의미 | 담당 |
| --- | --- | --- |
| **처음 쓸 이유 (실용)** | **내 운전을 아는 유일한 존재.** 매달 돈·시간·안전에서 몰랐던 것 하나와 할 일 하나를 알려 준다 | 운행 리포트 '꼭 알아야 할 3가지', 트립카드 요약 |
| **계속 쓸 이유 (정서)** | 혼자 운전하는 시간을 같이 보내고, 내 기록으로 자라는 친구 | 카링·트립카드·주행 한마디·수집 |

두 층은 하나로 이어진다: **카드를 남길수록 카링이 똑똑해지고, 똑똑해진 카링이 나에게 돈과 시간을 돌려준다.** 목적 하나를 고르는 1초가 아깝지 않은 이유다.

### "와, 이거 도움된다"의 순간

감탄은 대시보드가 아니라 **① 내 숫자로 ② 몰랐던 사실을 ③ 돈이나 시간으로 ④ 할 일 하나와 함께** 보여 줄 때 생긴다. 운행 리포트 맨 위 세 장이 이 일을 한다(4.14).

| 순간 | 카링이 하는 말(예) |
| --- | --- |
| 출발 시각 | "평일 출근, 7:50에 나가면 17분 빨라요 → **한 달에 2시간 12분** 아껴요" |
| 습관 → 돈 | "부드럽게 달린 날 전비가 19% 좋았어요 → **1년에 25만원** 아낄 수 있어요" |
| 목적별 비용 | "이번 달 충전비 9.3만원 중 **출근이 5.7만원**. 가까운 장보기를 묶으면 더 아껴요" |
| 안전 | "밤에 급조작이 낮보다 **3배** 많아요 → 밤엔 차간 거리를 한 대 더" |
| 생활 | "생활반경이 **25km로** 넓어졌어요, 처음 가 본 동네 3곳" |
| 혜택 (P1, 4.15) | "약 5일마다 잠실본동에서 충전해요 → 동네 충전소 **kWh당 50원 할인**"(예시 제휴, 광고 표시) |

대부분은 이 세 장만 보고 닫아도 가치를 느껴야 한다. 나머지 블록(①~⑨)은 '자세히 보기'다. 기록이 모자라는 첫 주에는 "출근 3번 더 달리면 가장 빠른 출발 시각을 알려 줄게요"처럼 **다가오는 인사이트**를 보여 주고, 그 사이의 가치는 트립카드와 카링이 맡는다.

### 60초 시연 흐름

출근 운전 → 카링 "앗, 천천히 가 줘~"(주행 한마디) → 주차, 카드가 뒤집히며 도착, '출근' 1탭 → 럭키박스 → (한 달이 꽉 차면) "짜잔! 축하해요" 알림 → 운행 리포트: **"7:50에 나가면 한 달 2시간 12분"**, **"1년에 25만원"** → 성장 리포트: 카링이 "네 출근 시간을 알게 됐어!"(똑똑함 +6)

**시연 모드 \[11/13\]:** debug 빌드 🛠 맨 위 '🎬 60초 시연 → 시연 준비'를 누르면 처음부터 다시 시작해 **이번 달 마지막 평일** 아침 7:48로 시계를 맞추고, 지난 4주 출근 16번(7:50 출발 41분 안팎·부드럽게 / 8:10 출발 57분 안팎·급조작)·장보기·식사 4번·주말 나들이 3번·충전 기록 30일·위치 동의를 채운 뒤 쌓인 상자와 축하 창을 미리 정리한다(아기카링 LV.16). 이어지는 **첫 D → P 한 번**만 연출한다: D 화면 숫자가 배속(1초에 0.5km)으로 오르고, 6초 안에 한마디가 없으면 "천천히 가 줘", P에서 출근 38.6km·41분·급조작 1번(집 잠실본동 → 회사 삼평동) 반짝 카드가 '출근' 추천과 함께 도착하고 P 5분 확정까지 건너뛴다. '완성하기' 한 번이면 성장 포인트·레벨업·럭키박스가 바로 나온다. 🛠 '한 달 마감'을 누르면 다음 달 1일로 넘어가며 '짜잔! 축하해요' 창이 뜨고, '리포트 보기'로 그달 리포트(저장됨)를 연다. 리포트에는 "7:50에 나가면 16분 빨라요 → 한 달 6시간 4분", "1년에 16.6만원", 충전비 3.3만원이 나온다(에뮬레이터 11/13 기준, 날짜에 따라 숫자는 조금 다르다). 다시 찍을 때는 '시연 준비'를 또 누른다. 영상에는 시뮬레이션 데이터임을 밝힌다.

이 흐름 하나로 "왜 쓰지?"와 "와, 도움된다"를 함께 전달한다. 상점·젤리·엠블럼은 계속 쓰게 하는 장치라 시연에서는 뒤로 뺀다.

**표기:** \[확정\] 사용자가 정한 것 · \[제안\] 구현하면서 채운 값(베타에서 조정) · \[예정\] 아직 만들지 않은 것.

## 1. 제품 정의

**MVP가 증명할 가설(변함 없음):** 운행 후 카드를 완성하고 카링의 변화를 확인하는 행동이 다음 운행에서도 반복된다.

**데이터 관점(변함 없음):** 기본 운행 기록은 자동으로 쌓이고(리포트의 재료), 카드 완성은 목적을 얻는 유일한 지점이다(목적별 분석과 개성의 재료). 운행·카드·보상 원장을 분리 저장한다.

## 2. 핵심 루프와 화면

사용자가 조작하는 순간은 주차 상태뿐이다. 주행 중에는 터치 요소가 없다.

1. **탑승 (P)** — 홈에서 차 안 대시보드 위의 카링이 인사한다. 미완성 카드가 있으면 재안내 시트가 먼저 뜬다.
2. **출발 (D)** — 기록이 자동 시작되고 홈이 주행 화면으로 바뀐다. 상황이 생기면 카링이 짧게 말한다.
3. **주차 (P)** — 새 트립카드가 뒤집히며 도착한다. 목적 하나를 고르면 완성.
4. **보상** — 운행 확정 + 카드 완성 시 성장 포인트, 젤리, 럭키박스 1개.
5. **변화 확인** — 단계·레벨·개성이 바뀌면 홈의 카링이 달라지고 근거가 보인다.
6. **꾸미기·수집** — 내 카링에서 장착, 배지 진열장, 상점.
7. **돌아보기** — 트립카드 요약·리포트로 내 생활을 본다.

## 4. 규칙과 수치

모든 수치는 `game/Rules.kt`와 각 규칙 파일에 모아 두었다. 단위 테스트가 이 값을 지킨다.

### 4.1 여정 판정 \[확정 11/12\]

| 규칙 | 값 |
| --- | --- |
| 시작 | P가 아닌 기어(에뮬레이터 속도가 0이라 속도 조건은 뺌) |
| 병합·확정 | P 전환 즉시 임시 카드, 5분 안에 다시 출발하면 같은 운행, P 5분 유지면 확정 |
| 앱이 꺼진 동안 | 다음 실행 때 주차 시각과 비교해 소급 확정(확정 시각 = 주차 + 5분), 기록 중 꺼지면 마지막 스냅샷(10초)을 주차로 |
| 카드 최소 기준 | 1km 이상 그리고 이동 3분 이상. 미달은 기록만 |
| 거리·시간 | 주행거리계 차분, 이동시간은 차속 기준(개발 빌드는 경과 시간) |

### 4.2 트립카드

- 상태: 임시 → 완성 → (미완성 방치 시) 만료. 확정 후 7일 안 재탑승 시 재안내, 재안내부터 24시간 뒤 만료. 만료돼도 운행 기록은 리포트에 남는다.
- 보상은 운행 확정 + 카드 완성 + 원장에 없음일 때 한 번.
- 목적 10종 \[확정\]: 출근·퇴근·업무·식사·장보기·여행·데이트·운동·취미·기타. 누구랑 5종: 혼자·가족과·친구와·연인과·기타.
- **목적 추천** \[제안\]: 주중/주말이 같고 출발 ±1시간인 지난 완성 카드의 최빈 목적(2장 이상).
- **등급** \[제안\]: 반짝 = 운전점수 85+(민트 무지갯빛 테두리), 특별 = 첫 카드 또는 100km 이상(금빛 + SPECIAL 리본). 보상은 같다.
- **카드 그림**: 목적별 풍경 × 출발 시간대 하늘(코드로 그린 원본). 목적을 고르면 풍경이 나타난다.

### 4.3 성장·단계·레벨

- 카드 1장 성장 포인트 = 10 + km + 이동 분, 상한 150 \[제안\].
- 단계 \[확정 11/13\]: 알 → 젤리링(첫 보상) → 아기링 1,500 → 꼬마링 3,500 → 버디링 6,000 → 소울링 10,000. 버디링·소울링은 **추후 공개**라 지금은 꼬마링에서 멈추고(포인트는 계속 쌓임) 실루엣으로 보인다. 그림은 젤리링=아기(서 있는 모습), 아기링=날개, 꼬마링=불꽃 \[확정 11/13\]. 내려가지 않는다. 꼬마링부터 지나온 모습으로 바꿀 수 있다(성장은 그대로).
- **레벨** \[확정 11/12, 공식은 제안\]: LV.n 필요 누적 = 40 × (n−1)^1.5, 최대 LV.50(13,720점).
- **레벨 엠블럼** \[확정\]: 오른쪽 위 **상태표의 이름 옆**에 다는 대표 뱃지(11/13 2차: 머리 위에서 옮김). 10레벨마다 화려해진다.

| 레벨 | 엠블럼 | 모습 |
| --- | --- | --- |
| 1–9 | 새싹 | 진주빛 원판 + 새싹 |
| 10–19 | 동 | 리벳 박힌 구리 테 + 리본 |
| 20–29 | 은 | 하늘빛 은 테 + 작은 날개 + 별 |
| 30–39 | 금 | 금 테 + 날개 + 보석 왕관 |
| 40–50 | 오로라 | 무지갯빛 수정 날개 + 보석 왕관 + 후광 |

레벨업 때 축하 창과 레벨당 젤리 50.

### 4.4 개성 \[11/13 2차 확정\]

최근 보상 받은 카드 10장(3장 미만이면 기본형). 몸 분위기 = 아침·낮 출발이 많으면 **낮길형(이마 위로 올려 쓴 드라이빙 고글 + 햇살 테두리)**, 저녁·밤 출발이 많으면 **밤길형(이마 헤드램프 + 머리 위를 도는 반딧불 셋 + 달빛 테두리)**, 동률은 최근 카드 쪽. 눈과 몸 색은 가리지 않는다. 대표 장식(흰 동그라미 배지로 크게) = 최빈 목적(출근·퇴근 넥타이, 업무 업무 배지, 데이트 하트 핀, 여행 작은 배낭, 취미 음표 핀, 식사 숟가락 핀, 장보기 장바구니, 운동 스포츠 밴드, 기타 없음), 심장빛 = 평균 운전점수 85+. 운전점수 = 100 − 5 × (급조작 ÷ 10km), 하한 40.

### 4.5 럭키박스·자동차 꾸미기·배지

| 항목 | 값 |
| --- | --- |
| 지급 | 보상 1회당 1개, 하루 최대 5개 |
| 내용 | 보너스 성장 포인트 5~30 + 30% 배지 · 35% 자동차 꾸미기(아이템 12 + 색 7 균등) |
| 상자 빛 힌트 | 라벤더 = 포인트, 금빛 = 배지, 민트 = 꾸미기 \[제안\] |
| 모두 받기 | 2개 이상이면 한 번에 열고 요약 |
| 자동차 꾸미기 \[확정\] | 휠캡 4(데이지·클로버·별사탕·바람개비), 안테나 4(새싹·하트·별·행성), 뒤쪽 소품 4(여행가방·캠핑 배낭·피크닉 바구니·서핑보드). 자리마다 하나 |
| 스타일 세트 | 같은 테마 3자리 완성: 새싹 드라이브·주말 여행자·별빛 탐험가·구름 산책 |
| 차체 색 | 펄 화이트(기본) + 7색 수집 + **오로라**(배지 6종 세트 보상) |

**배지 = 내 운전 습관의 기록** \[확정 11/12\]: 배지가 나오면 그 여정에 맞는 것 중에서 고른다.

| 배지 | 얻는 법 |
| --- | --- |
| 아침 햇살 🌅 | 아침(5~10시) 출발 |
| 밤하늘 별 🌙 | 밤(21~5시) 운행 |
| 출근길 커피 ☕ | 출근·퇴근 카드 |
| 주말 나들이 🧺 | 토·일요일 여정 |
| 단골길 🛣️ | 같은 목적 3번 넘게 완성 |
| 민트 하트 💚 | 운전점수 85+ |

같은 배지를 더 받으면 동(1) → 은(3) → 금(5). 6종을 모두 모으면 오로라 차체 색. 진열장(카링 탭 '🏅 배지')에서 메달·등급·다음 등급까지·얻는 법을 본다. 내 카링에서 하나를 **대표 배지**로 단다.

### 4.6 젤리와 상점 \[확정 11/12, 값은 제안\]

- 젤리는 성장 포인트와 따로 모은다. 써도 성장은 줄지 않는다.
- 적립: 카드 보상 15 + 5km마다 1(최대 +25), 럭키박스 보너스 점수만큼, 이미 가진 배지·꾸미기·색이 또 나오면 20, 레벨업 50. 이전 기록은 불러올 때 한 번 채운다.
- 상점: 자동차 꾸미기 300, 차체 색 400, 배경 테마 500(차 안 배경을 아침·낮·저녁·밤 중 하나로 고정, 자동으로 되돌릴 수 있음). 엠블럼은 레벨로만.
- \[예정\] 카링 스킨(새 그림 필요), 엠블럼 테두리, 시즌 상품.

### 4.9 트립카드 앨범·요약·상세 \[확정 11/12\]

- 앨범: 주는 날짜별, 월은 주별, 분기·년은 월별로 묶어 5열. 작은 카드에 풍경·목적·날짜·거리·시간·점수·보상, 등급 테두리.
- 요약: 한 줄(평일·주말 대표 루틴 + 생활반경, 예 "평일 아침엔 잠실본동 → 삼평동 출근 · 생활반경 25km, 새 동네 1곳"), 왜(목적 비중)·언제(요일×시간대)·어디(자주 간 동네 3곳)·누구랑(혼자/함께), 생활반경(작은 과녁·지난 기간 대비·새 동네), 루틴(같은 목적·주중/주말·시간대 3회+, 도착 동네·함께한 사람은 절반 넘을 때만)·특별한 여정. 목적·루틴을 누르면 그 카드만.
- 상세: 큰 카드, 출발 → 도착 동네, 거리·시간, 점수·급조작, 효율, 같은 목적 평균과 차이, 같은 길(또는 같은 목적) 중 몇 번째, 보상 → '고치기', '같은 목적 카드 보기'. 임시 카드는 바로 완성 시트.

### 4.10 위치(동네) \[확정 11/12 '2단계까지 위치 동의'\]

- 리포트 ⑤ '위치 켜기' → FusedLocation 런타임 권한. 출발·도착 때 위치로 행정동을 판정하고 **코드만** 저장한다. 좌표·경로는 저장하지 않는다. 판정은 앱 안 경계 데이터(행정동 3,482)로 하고 밖으로 보내지 않는다.
- '위치 끄기'는 지금까지의 동네 기록도 지운다.
- 집 동네 = 가장 많이 출발한 동네(하루 첫 운행 2배, 2회 이상). 활동 반경 = 집 밖 도착지 80%가 드는 동네 중심 간 거리.

### 4.11 운행일지 \[확정 11/12 'QR → 폰 메일'\]

차에는 메일 앱이 없어서, 일지(기간 요약·개선·절약·차량 상태·운행 목록)를 mailto 주소로 만들어 QR로 보여 준다. 폰 카메라로 찍으면 내 주소·제목·본문이 채워진 메일 쓰기 화면이 열린다. 서버·계정 없음. QR 판독을 위해 1,100바이트 안으로 운행 목록을 줄이고 "외 N건"을 붙인다. 받는 주소는 기기에만 저장한다.

### 4.12 차량 상태

Vehicle SDK `Tire`·`Safety`·`Odometer`·`EvBattery`·`Fuel`에서 리포트를 열 때 한 번 읽는다: 타이어 4바퀴 psi(부족 기준 대비), 엔진오일·브레이크액 수준, 워셔액 부족, 남은 주행 가능 거리, 배터리/연료 %, 누적 주행거리, 켜진 주의 경고등(종합·TPMS·엔진·오일 압력·냉각수·ABS·ESC·에어백·조향·보조 배터리·EV 시스템·구동 배터리·출력 제한·회생 제동·문 열림). 값이 없거나 0이면 —.

### 4.13 친구 초대 \[확정 11/13, 비활성\]

초대한 친구와 **같은 시간에 운전하고 있을 때 서로 어디쯤 달리는지** 볼 수 있는 기능. 둘 다 운전 중일 때만 주고받고, 주차하면 멈춘다. 지금은 설명·초대 코드와 '초대하기 · 곧 열려요'만 보인다.

열 때의 원칙 \[제안\]: 둘 다 켰을 때만 공유, D 화면에는 "○○도 달리는 중 · 약 12km" 같은 글자만(지도는 주차 후), 기록에 남기지 않음. 함께 열면 좋은 것: 초대 보상(둘 다 젤리 + 한정 꾸미기), 친구 카링 놀러가기(360°·엠블럼·배지 구경, 응원 스티커), 함께 챌린지(협동형 안전 운전 목표).

### 4.14 꼭 알아야 할 3가지 \[확정 11/13, 기준값은 제안\]

운행 리포트 맨 위. 아래 다섯 가지 중 조건을 채운 것을 우선순위 순으로 3장, 모자라면 다가오는 인사이트로 채운다. 카드마다 제목(몰랐던 사실) · 큰 숫자(돈·시간) · 근거 한 줄 · 💡 할 일 하나 · 카링이 본 기록 수.

| 순서 | 인사이트 | 조건과 계산 |
| --- | --- | --- |
| 1 | 출발 시각 ⏰ | 최근 60일 평일, 같은 길(출발·도착 동네, 위치가 없으면 출근·퇴근·업무)을 출발 시각 20분 칸으로 나눈다. 칸마다 2번 이상, 평소 칸 ±1시간 안에서 평균 이동시간이 5분 넘게 짧은 칸이 있으면: 한 번에 아끼는 분 × 한 달 그 길 횟수 |
| 2 | 습관 → 돈 💚 | 운전점수 85+ 운행과 아닌 운행의 거리 가중 효율이 5% 넘게 차이 나면: 이 기간 주행량을 1년으로 늘려 (나쁜 효율 − 좋은 효율) 에너지 × 단가. 모두 부드러우면 칭찬 카드 |
| 3 | 비용 💰 | 이 기간 에너지비(운행별 효율, 없으면 평균)와 가장 큰 목적. 15km 미만 장보기·식사가 3번 이상이면 절반을 묶었을 때의 거리·금액 |
| 4 | 안전 🌙 | 밤 100km당 급조작이 낮의 2배 이상(밤 3번 이상), 또는 밤 운전이 직전 기간보다 50% 이상 늘면 |
| 5 | 생활 🗺️ | 위치 동의 시 활동 반경 20% 이상 확대 또는 새 동네 |
| — | 다가오는 🔜 | "출근 N번 더", "운행 N번 더", "목적 카드 3장 더" |

원칙: 숫자는 모두 내 기록에서만 나온다(평균·타인과 비교하지 않음). 할 일은 한 가지, 운전 중이 아니라 다음 출발 전에 할 수 있는 것. 생성형 AI는 쓰지 않는다.

### 4.15 생활반경 혜택 \[11/13 에뮬레이터 적용, 예시 제휴\]

**한 줄:** 카링이 아는 내 생활반경과 운행 습관으로, 내가 실제로 다니는 곳의 **차 관련 혜택**을 리포트에서 알려 준다. "돈과 시간을 아끼는 힌트"를 행동으로 잇는 마지막 단계다.

**우선순위: 차와 직접 엮이는 혜택이 먼저다.**

| 우선 | 혜택 | 언제 보여 주나(트리거) | 카링이 하는 말(예, 예시 제휴) |
| --- | --- | --- | --- |
| 1 | **충전·주유 할인** | 충전(주유) 기록이 쌓였고(2회+), 자주 출발·도착하는 동네가 있을 때. 남은 양이 낮은 날 다음 리포트 | "약 5일마다 충전해요, 주로 잠실본동 → 동네 충전소 kWh당 50원 할인" |
| 2 | **주차 할인** | 같은 동네로 식사·장보기·업무가 3번 이상 | "청담동에 식사하러 3번 갔어요 → 근처 주차장 2시간 무료" |
| 3 | **세차** | 장거리(100km+) 여행 뒤, 주말 나들이 뒤, 또는 마지막 세차 혜택 이후 2주 | "주말에 230km를 달렸어요 → 집 근처 손세차 20% 할인" |
| 4 | **정비소** | 차량 상태 경고(타이어 공기압·엔진오일·워셔액·경고등) 또는 누적 주행거리 구간(예: 1만km마다) | "앞 왼쪽 타이어 공기압이 낮아요 → 내 동선 3km 안 정비소 점검 무료" |
| 5 | 생활 혜택(후순위) | 운동 카드 → 헬스장·웰니스, 식사 → 맛집, 장보기 → 마트 | "운동 카드 8번, 주로 청담동 저녁 → 근처 헬스장 첫 달 할인" |

**보여 주는 곳과 규칙**

- 운행 리포트 '꼭 알아야 할 3가지' 아래에 **기간당 1장**. 트립카드 상세에는 그 동네 혜택이 있을 때만 작은 줄 하나.
- 모든 혜택 카드에 **"광고 · 제휴"** 표시. 근거 한 줄(내 기록)과 혜택 한 줄, 💡 할 일 하나.
- **주행 중에는 보이지도 말하지도 않는다.** 주행 한마디에 혜택을 넣지 않는다(친구가 영업사원이 되는 순간 신뢰가 깨진다).
- 같은 혜택은 닫으면 30일 동안 다시 보이지 않는다. 혜택을 하나도 원치 않으면 끌 수 있다.
- 순위: 차 관련(1~4) > 생활(5). 같은 종류면 내 기록과 더 강하게 이어지는 것(횟수·최근성·거리) 먼저.

**동의와 개인정보**

- 생활반경 보기용 위치 동의(4.10)와 **별도의 선택 동의**: "내 동네와 운행 습관으로 혜택 고르기".
- **차 안에서만 매칭:** 혜택 목록(동네 코드·종류·내용·기간)을 차로 내려받고, 내 동네·습관과의 매칭은 차 안에서 한다. 내 위치·기록은 밖으로 나가지 않는다. 노출·사용 지표만 동의하에 익명 집계.
- 위치가 꺼져 있으면 동네 없이 목적·차량 상태만으로 고른다(예: 경고등 → 정비 점검 혜택).
- 사업화 전 확인: 위치정보법상 위치기반서비스 신고, 광고성 정보 표시 기준(법률 검토 필요).

**데이터(안)**

```kotlin
data class BenefitOffer(            // 서버에서 내려받는 혜택 목록(개인정보 없음)
  val id: String, val kind: BenefitKind,          // CHARGE·FUEL·PARKING·WASH·SERVICE·LIFE
  val dongs: List<String>,                        // 적용 행정동(비면 전국)
  val title: String, val detail: String, val partner: String,
  val validUntil: Long, val trigger: String)      // 예: "refuel>=2", "visits(MEAL|SHOPPING)>=3", "warning:TPMS"
data class BenefitSeen(val offerId: String, val shownAt: Long, val dismissedAt: Long?, val usedAt: Long?)
```

**데모(11/15) 범위 (11/13 적용):** 앱에 들어가 있다. 리포트 혜택 카드(선택 동의 → 기간당 1장 → 혜택 받기·닫기 30일·끄기), 트립카드 상세의 그 동네 혜택 한 줄. 혜택 목록 14개는 모두 **"예시 제휴"** 가상 혜택(예시 충전소·예시 주차장 …)이고 실제 가게·브랜드 이름은 쓰지 않는다. 우선순위 점수: 정비 100, 충전·주유 90, 주차 80, 세차 70, 생활 40+.

**측정:** 혜택 카드 노출 대비 열람·사용률, 닫기율(높으면 관련성 문제), 혜택 켠 사용자의 리포트 재방문율. 혜택 때문에 앱을 끄는 비율이 늘면 노출 수를 줄인다.

**사업 모델:** 제휴처 수수료(노출·사용 기준). 차 관련 혜택은 충전 사업자·주차장·세차·정비 네트워크와의 제휴로 시작하는 것이 자연스럽다.

## 5. 데이터 모델

v0.1은 Room DB를 제안했지만, 구현은 **상태 전체를 JSON 한 덩어리로 SharedPreferences(`mycarling_v1`)에 저장**하고 한 번에 바꿔 쓴다. 보상 1회는 원장(`rewards`) 키 검사로 보장한다. 시계(`Clock`)와 저장소(`Storage`)는 주입형이라 단위 테스트가 가능하다.

```kotlin
data class CarlingData(
  // 기록·카드·보상
  val trips: List<TripRecord>, val cards: List<TripCard>, val rewards: Map<Long, Reward>,
  val boxes: List<LuckyBox>, val dailyBoxes: Map<String, Int>, val refuels: List<Refuel>,
  // 카링
  val totalGp: Int, val stage: Stage, val look: Stage?, val personality: Personality,
  val snapshots: List<PersonalitySnapshot>, val stageHistory: List<StageChange>,
  // 수집·꾸미기
  val badges: Map<Badge, Int>, val displayBadge: Badge?, val parts: Map<CarPart, Int>,
  val equipped: Map<CarSlot, CarPart>, val colors: Map<CarColor, Int>, val carColor: CarColor?,
  val styles: Set<CarStyle>,
  // 레벨·젤리·상점·화면
  val levelSeen: Int, val jelly: Int, val themes: Set<TimeBucket>, val theme: TimeBucket?,
  val cabin: CabinView, val homeAngle: Int?,
  // 사용자 입력·설정
  val customTags: List<String>, val customPurposes: List<String>, val consented: Boolean,
  val locationConsent: Boolean?, val logEmail: String?, val kwhPrice: Int, val fuelPrice: Int,
  // 기타
  val talks: Map<Talk, Int>, val events: List<EventLog>, /* unseen* 안내 플래그 */)

data class TripRecord(tripId, status, startedAt, lastParkAt, confirmedAt, lastSnapshotAt,
  distanceKm, movingSec, harsh, simulated, ev, startPercent, endPercent, startWh, endWh,
  efficiency, startDong, endDong)   // startDong·endDong: 행정동 코드, 동의했을 때만

data class TripCard(tripId, number, state, createdAt, completedAt, purpose, companion,
  tags, customPurpose, remindedAt, expiredAt)
```

불러올 때 자동 이전: 예전 목적(출퇴근·외근·가족과 함께) → 새 목적, 젤리 첫 적립, 레벨 기준, 배지 6종 보유자 오로라 지급.

이벤트 로그: v0.1 목록 + `level_up`, `shop_*`, `talk_*`, `location_on/off`, `card_edited`, `charged/refueled`, `unequipped_all` 등.
