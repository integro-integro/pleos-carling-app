## 다시 찍기

`tools/demo-video/`: `lib.sh`(에뮬레이터 호스트 녹화 `adb emu screenrecord`, 탭, 시뮬레이터 명령), `segments.json`, `edit.py`(`NARR_DIR=tools/demo-video/narration-julian python3 edit.py`; 파일이 없는 장면은 macOS TTS로 대신 읽는다), `strip.py`(장면 타임라인 확인). 기기 안 `screenrecord`는 프레임이 많이 빠져 호스트 녹화(15fps)를 쓴다.

debug 빌드 adb 명령(`DevCommands.kt`): `reset`, `at`(날짜·시각), `consent`, `arm`(다음 주행 거리·시간·급조작·동네), `skip`(분), `ignition`, `commute9`·`night6`·`weekend3`·`experiment`·`refuels`, `closeMonth`, `cabin`, `hideDev`, `riding`, `tidy`(상자 열기·축하 창 정리), `typeName`(이름 짓기 창에 한 글자씩 입력).

```bash
adb shell am broadcast --user 10 -a work.integro.carling.DEV --es cmd typeName --es name 몽글이
```

주의: 에뮬레이터를 새로 켜면 시간대가 LA로 바뀔 수 있다(`adb shell service call alarm 3 s16 Asia/Seoul`). 기어 콘솔은 브라우저에 http://127.0.0.1:8088 이 열려 있어야 동작한다. 운행일지 메일 주소는 예시 주소(mycarling.demo@example.com)를 썼다.
