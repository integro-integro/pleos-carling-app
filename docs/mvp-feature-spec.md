# 모두의 카링 기능 명세 — 공모전 MVP와 이후 범위

- 작성 기준일: 2026-11-04
- 기준 자료: 공모전 공식 사이트와 공지, Pleos 개발 문서, 에뮬레이터 시험, 현재 `dev` 코드, `모두의카링 서비스 시각화 v1.pdf`, `CARLING_Growth_Evolution_v0.4.docx`

## 1. 결론

**개발된 기능은 대부분 MVP에 넣을 수 있다.** SDK 때문에 빠져야 하는 기능은 Pleos ID 연동뿐이다. 다만 새 기능을 늘리기보다, 아래 세 가지를 먼저 해야 한다.

1. 공식 SDK로 교체한다. FusedLocation과 TextToSpeech는 이미 제공되는데, 앱은 아직 대체 경로를 쓴다. 심사 항목인 기술 활용성에 바로 영향을 준다.
2. 주행 중심의 한 흐름을 끊김 없이 시연할 수 있게 만든다.
3. 기획과 구현이 어긋난 규칙을 정리한다. 제출 서류 내용이 사실과 다르면 선정이 취소될 수 있다.

- 실제 이동: `adb emu geo fix`로 좌표를 옮겨 시험했다. 실차 주행과 절전 동작은 확인하지 못했다.

## 4. MVP 명세

### M1 — 11/15 제출본

진행 상황은 아래 표의 상태 열을 본다.

| ID | 요구사항 | 완료 기준 | 상태 |
|---|---|---|---|
| M1-1 | 경로 수집을 FusedLocation으로 교체. 권한 `pleos.car.permission.FUSED_LOCATION`(dangerous). 없으면 NaviHelper로 대체 | 주행 중 좌표가 쌓이고 저장됨 | 완료(에뮬레이터) |
| M1-2 | 음성을 TextToSpeech SDK `ON_DEVICE`로 교체. 권한 `pleos.car.permission.TTS_SERVICE`. 끄기 버튼 추가. 실패하면 무음 | 에뮬레이터에서 주차 인사 소리를 확인 | 재생 완료 로그까지 확인, 소리는 미확인 |
| M1-3 | 속도 데이터가 없으면 안전 보너스를 주지 않음 (v0.4 4장) | 단위 테스트 추가 | 완료 |
| M1-4 | 화면 밖 경로 기록 시험 | 앱을 내린 채 주행해도 경로가 남음. 안 되면 영상과 기획서에 제한을 명시 | 완료(에뮬레이터, 내비가 앞에 있는 상태). 실차는 미확인 |
| M1-5 | release APK를 다시 빌드해 `apk/`에 반영 | `팀명_앱이름_release.apk`가 설치·실행됨 | 새 키로 서명, 설치·첫 운전까지 확인. 제출 전 팀명으로 다시 빌드 필요 |
| M1-6 | 시연 영상(화면 녹화) | 첫 운전→부화→주행 위젯→트립카드→지도→진화 | 대기 |
| M1-7 | README 제출 요건 확인, 비공개 저장소라면 심사 계정 초대 | 마감 전 접근 확인 | README 완료, 초대는 사용자 작업 |

### M2 — 12/3 PT

| ID | 요구사항 | 완료 기준 |
|---|---|---|
| M2-1 | release에서 쓸 수 있는 시연 모드(숨김 진입). 날짜 건너뛰기와 표본 주행 | 시연 시나리오를 5분 안에 재현 |
| M2-2 | 기록 삭제, 동의 철회 시 삭제 안내 | 지도·경로·위치 기록이 지워짐 |
| M2-3 | 진화카드를 기획대로: 그날 최종 트립 수로 추첨, 확정 시점 통일 | 18·22·25%가 실제 적용됨 |
| M2-4 | 계열·진화 때 이유 문구 표시 | 계열별 문구 확인 |
| M2-5 | 지도 라벨·밀도 화면 확인과 조정 | 많은 길에서도 읽을 수 있음 |
| M2-6 | PT 대비 리허설: 네트워크 끊김, 에뮬레이터 Cold boot, 주행 중 앱 재시작 | 끝까지 중단 없이 진행 |

**여유가 있을 때만:** 말 걸기를 SpeechToText로 구현. 기술 활용성에 도움이 되지만 시험 전이라 필수에 넣지 않는다.

### MVP 시연 시나리오

1. 정차 상태에서 알 등장
2. 기어 D: 주행 위젯과 음성 한마디, 터치 없음
3. 기어 P: 트립카드와 알 부화
4. 이름 짓기와 첫 교감
5. 카드 저장으로 MP 획득, 지도에 길 점등
6. 충전구 열기: 함께 밥 먹기와 XP
7. 시연 모드로 D14 계열 결정, D30 진화 장면

## 5. MVP 이후

| 기능 | 뒤로 미루는 이유 | 시기 |
|---|---|---|
| Pleos ID 계정 귀속, 차량 변경 시 유지 | 공개 API 없음 | API 공개 후 |
| 길에서 만나는 새 친구, 희귀 카링 | 미구현, 아트와 수집 체계 필요 | 출시 1단계 |
| 특별 퀘스트 본편(메모, 추억 묶음, 여정 회고) | 미구현. MVP는 저장 카드 수로 대체 | 출시 1단계 |
| 기억 분류, 동행, 목적 입력 | 미구현, 입력 화면 필요 | 출시 1단계 |
| 지도 기간 필터(7·30·90·180일) | 미구현, 길별 날짜 기록 필요 | 출시 1단계 |
| 구간 단위 새 길 판정(20~30%) | 도로 대응 필요, 실주행 검증 필요 | 실차 검증 후 |
| 연료 부족 알림→주유 판정, 내연기관 지원 | 주유 이벤트 미확인 | SDK 확인 후 |
| 동승자 계층 | 탑승 감지 API 미확인 | 확장 |
| Gleo·LLM 대화 | 공모전 안내 SDK 5종에 없음 | 확장 |
| 음성 이름 짓기 | STT 미시험 | STT 시험 후 |
| 표준 행동에 맞춘 XP 곡선 재조정 | 실사용 데이터 필요 | 출시 전 |
| 앱마켓 심사 대응 | 권한 사전 승인, 약관, 위치정보 신고 확인, 더미 데이터 제거, 게임 분류 시 주행 중 화면 제한 | 수상 후 |

## 6. 기획서에 적으면 안 되는 것

공지에 따르면 제출 서류 내용이 사실과 다를 경우 선정이 취소될 수 있다. 다음은 구현된 기능처럼 쓰지 않는다.

- 차를 바꿔도 이어지는 카링
- 실제 산길·해안을 판정하는 계열
- 새 친구와 희귀 카링
- 구간 단위 경로 판정
- 메모·묶음·회고 퀘스트

## 8. 사무국 문의 사항 (appdevchallenge@hyundai-partners.com)
