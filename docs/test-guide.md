# 카링 테스트 가이드

처음부터 끝까지 순서대로 따라 하면 모든 기능을 확인할 수 있다. 전체 약 20분.

- 기준 버전: v0.3.0 (2026-11-04 현재 코드에 맞춰 2~7장을 고쳤다. 고친 순서를 처음부터 끝까지 따라 해 보지는 않았다)
- 테스트 환경: Pleos Connect Emulator v2.1.0
- 명령은 모두 프로젝트 폴더(`pleos-carling-app`)에서 실행한다.
- 아래 명령에서 `adb`는 `~/Library/Android/sdk/platform-tools/adb`를 뜻한다. PATH에 없으면 전체 경로로 입력한다.

---

## 0. 준비 (최초 1회)

1. Android Studio를 열고 **Device Manager**에서 `Pleos_Connect_v2.1.0`을 실행한다.
   - 부팅에 1~2분 걸린다. Cold boot로 설정되어 있어야 차량 신호가 동작한다.
2. 가상 콘솔(차량 조작 화면)을 연결한다.
   ```bash
   adb forward tcp:8088 tcp:8088
   ```
   브라우저에서 http://127.0.0.1:8088/ 을 연다. **에뮬레이터를 재부팅할 때마다 이 연결을 다시 해야 한다.**
3. 가상 콘솔에서 자주 쓰는 조작:
   | 하고 싶은 것 | 위치 |
   |---|---|
   | 기어 P / D | Emulation Controls → All domains → **Gear Selection** |
   | 충전 | Emulation Controls → Energy → **Charge Port** Open, **Charge Switch** On |
   | 가속 / 감속 | 메인 화면의 **ACCEL** / **BRAKE**를 누르고 있기 |

## 1. 처음부터 시작하기 (데이터 초기화)

앱 데이터를 지우면 알 상태부터 다시 시작한다. Pleos 에뮬레이터의 운전자 계정은 **user 10**이다.

```bash
adb shell pm clear --user 10 work.integro.carling
```

> debug 빌드라면 홈 화면 왼쪽 위 🛠 → **알부터** 버튼으로도 초기화할 수 있다.

### 어떤 빌드로 테스트할지

| | debug | release |
|---|---|---|
| 용도 | 개발, 데모 촬영 | 제출본 확인 |
| 개발자 도구 (🛠 가상 주행, 단계 건너뛰기) | 있음 | 없음 |
| 설치 | `./gradlew installDebug` | `./gradlew submissionApk -PteamName=팀명` 후 `adb install -r -g apk/팀명_CARLING_release.apk` |

- **debug와 release는 서명이 달라서 서로 덮어 설치할 수 없다.** 바꿀 때는 먼저 지운다.
  ```bash
  adb uninstall work.integro.carling
  ```
- `adb install`에 `-g`를 붙이면 권한이 미리 허용된다. 실제 사용자처럼 권한 창까지 확인하려면 `-g` 없이 설치한다.

## 9. 세로(좁은) 창

Pleos에서 앱 두 개를 나란히 띄우면 각 앱이 세로 창이 된다. 에뮬레이터에서 빠르게 확인하려면 화면 밀도를 올려 창을 좁게 만든다.

```bash
adb shell wm density 320
```
카링을 열면 캐릭터 → 이름 → 상태 패널이 위아래로 쌓이고 스크롤된다. 확인이 끝나면 반드시 되돌린다.
```bash
adb shell wm density reset
```

## 10. 로그로 확인하기 (선택)

```bash
adb logcat | grep -E "TripTracker|SpeedMonitor|BootReceiver|TripService|NaviPlaces"
```
| 로그 | 뜻 |
|---|---|
| `TripTracker: 주행 시작` / `주행 종료: 12s, place=true` | 주행 기록, 위치 판정 여부 |
| `TripTracker: 진행 중 주행 복구` | 주행 중 앱 재시작 후 이어서 기록 |
| `SpeedMonitor: 급조작 감지: 5.5 m/s²` | 급가속·급감속 |
| `BootReceiver: 수신: BOOT_COMPLETED`, `TripService: 포그라운드 서비스 시작` | 자동 시작 |

## 알려진 제한

- 음성은 나오지 않는다 (에뮬레이터 TTS 초기화 실패, Pleos TTS SDK 대기).
- 에뮬레이터 시계가 실제와 다를 수 있다. 시간대(빛)와 성격은 에뮬레이터 시각을 기준으로 판정된다.
- 실제 이동 경로는 에뮬레이터에서 확인할 수 없고 실차에서 확인해야 한다.
