# 카링월드 테스트 가이드

- 환경: Pleos Connect Emulator v2.1.0, 운전자 계정 user 10. 차량 신호를 쓰려면 Cold boot로 켠다.
- `adb`는 `~/Library/Android/sdk/platform-tools/adb`를 뜻한다.

## 준비

```bash
JAVA_HOME=/opt/homebrew/opt/openjdk@17 ./gradlew installDebug
```

```bash
adb shell pm clear --user 10 work.integro.carling
```

```bash
adb forward tcp:8088 tcp:8088
```

브라우저에서 http://127.0.0.1:8088/ → Gear Selection으로 기어를 바꾼다.

## 시나리오 (debug 빌드, 오른쪽 위 🛠)

| 단계 | 하는 일 | 확인할 것 |
|---|---|---|
| 1 | 앱 실행 | 동의 창 → 라벤더 배경, 젤리알, "P · 함께 출발해요", 하단 탭 3개 |
| 2 | 지금 주차한 운행 18km | 승차권 카드 시트(임시). 목적을 고르기 전에는 '완성하기'가 꺼져 있음 |
| 3 | 출퇴근 → 완성하기 | "운행이 확정되면 약 55점" 알림, 보상은 아직 없음 |
| 4 | 5분 지나기 | 확정 → 알에 첫 금 연출, 럭키박스 1개 |
| 5 | 럭키박스 → 상자 누르기 | 뚜껑이 열리고 보너스 포인트와 배지/자동차 아이템 |
| 6 | 아침 출퇴근 9장 + 포인트 +1,000 | 아기카링 연출과 이름 짓기, 살구빛 빛무리·넥타이·반짝이는 심장, 근거 문구 |
| 7 | 밤 외근 6장 | 최근 10장 교체로 개성 변화 알림 |
| 8 | 지금 주차한 운행 → 나중에 → 5분 → 다시 시동 | 재안내 시트 "24시간 안에" → 24시간 지나기 → 만료, 리포트 운행 수에는 남음 |
| 9 | 짧은 운행 0.6km | 카드 없음, 리포트 운행 횟수 +1(미분류·기준 미달) |
| 10 | 트립카드 탭 | 최신순, 상태 필터, 완성 카드 눌러 목적 고치기 |
| 11 | 리포트 탭 → 기간 전환 | 핵심 발견, 증감, 날짜별 막대, 목적별 비중, 생활 패턴, 성장 내역 |
| 12 | 콘솔에서 기어 D → P | D 화면(달리는 카링, 숫자 2개, 터치 없음) → P 즉시 카드 시트 |
| 13 | P → 5분 안에 D → P | 카드 한 장, 같은 운행으로 합산 |

debug 빌드는 카드 기준을 낮춰 기어만 바꿔도 카드가 생긴다. 에뮬레이터 주행거리는 변하지 않아 0.0km로 보인다.
