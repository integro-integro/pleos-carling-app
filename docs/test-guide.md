# 카링월드 테스트 가이드

- 환경: Pleos Connect Emulator v2.1.0, 운전자 계정 user 10. 차량 신호를 쓰려면 Cold boot로 켠다.
- `adb`는 `~/Library/Android/sdk/platform-tools/adb`를 뜻한다.

## 준비

```bash
JAVA_HOME=/opt/homebrew/opt/openjdk@17 ./gradlew installDebug
```

```bash
adb shell pm clear --user 10 work.integro.carling
```

```bash
adb forward tcp:8088 tcp:8088
```

브라우저에서 http://127.0.0.1:8088/ → Gear Selection으로 기어를 바꾼다.

## 시나리오 (debug 빌드, 오른쪽 위 🛠)

| 단계 | 하는 일 | 확인할 것 |
|---|---|---|
| 1 | 앱 실행 | 안내창 뒤 빈 방과 젤리 알, Lv.1 |
| 2 | 유효 운행 1회 | 카드 자동 저장 → Lv.2와 알의 첫 금 → 러그가 놓임, 친밀도 +1 |
| 3 | 조건 미달 운행 | 카드 없음 |
| 4 | 유효 운행 6회 이상(같은 날) | 6번째 카드에 'XP 지급 5회 완료 · 이번 운행 XP 0', 아이템은 지급 |
| 5 | 다음 진화 조건 채우기 → 성장과 진화 | 조건 3개 충족, '알에서 깨어나기' |
| 6 | 깨어나기 → 이름 짓기 | 아기 카링이 방을 돌아다니고 침대·스탠드·라디오에서 반응 |
| 7 | Lv10 이상에서 하단 '공간' | 거실 열림, 주방 Lv13·화장실 Lv16·작업실 Lv18 잠금, 정원 이후 추후 공개 |
| 8 | 오른쪽 '축소' → 침실 문(복도) → 거실 | 카링이 문으로 걸어가 화면이 바뀌고 거실 계단 아래에서 나옴. 거실에는 2층으로·화장실·주방 이름표 |
| 8-1 | 침실에서 소파·침대·머그컵 누르기 | 소파에 앉기, 침대에 누워 자기, 커피 맛있다고 하기 |
| 8-2 | 하단 '카링월드' | 지도에서 집이 빛나고, 정원·해변·숲·하늘 전망대·하늘 섬은 안개와 자물쇠 |
| 9 | 하단 '도감' | 공간별 획득 수, 없는 아이템은 실루엣 |
| 10 | 하단 '트립카드' → 필터 | 오늘·지난 7일·14일·30일·전체마다 장수와 거리·XP 합계가 바뀜 |
| 11 | 다음 진화 조건 채우기 → 계열 선택 | 5계열 중 선택, '정원은 곧 열릴 거예요' |
| 12 | 기어 D → 10초 → P | D 동안 게임 화면 없음, P 후 카드 표시(시뮬레이션 표시 없음) |

debug 빌드는 기어만 바꿔도 유효 운행으로 처리한다. release 빌드의 2km·5분 판정은 실차 또는 가속 조작으로 확인한다.
