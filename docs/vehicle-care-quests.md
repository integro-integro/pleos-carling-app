# 차량 상태 연동 · 돌봄 퀘스트 설계 (초안, 2026-11-07)

카링은 "자동차의 작은 심장"이다. 차가 아프면 카링도 아프고, 운전자가 차를 돌보면 카링과 더 가까워진다.

## 1. 쓰는 차량 신호 (Pleos Vehicle SDK 2.3.2에서 확인한 리스너)

| 상황 | SDK 리스너 | 판정 (1차 제안값) |
|---|---|---|
| 타이어 공기압 부족 | `TirePressureListener` | 네 바퀴 중 하나라도 권장값보다 낮음 (예: 30psi 미만 또는 경고 플래그) |
| 연료 부족 | `FuelPercentListener`, `RangeRemainingListener` | 연료 15% 이하 또는 주행 가능 거리 50km 이하 |
| 전기차 배터리 부족 | `EvBatteryStateOfChargeListener` (이미 사용 중) | 20% 이하 |
| 엔진오일 이상 | `OilLevelStateListener` | 오일량 '부족/점검' 상태 |
| 워셔액 부족 | `LowWasherFluidWaringListener` | 경고 켜짐 |

- 에뮬레이터 가상 콘솔에서 값을 바꿔 시험한다. 실차 판정값은 시연 차량에서 다시 맞춘다.
- 신호를 못 받으면(권한 없음, 미지원 차종) 그 퀘스트는 생기지 않는다. 지어내지 않는다.
- 주행 중에는 화면 대신 짧은 음성 한 마디만 하고, 반응 연출과 퀘스트 카드는 주차(P) 후에 보여준다.

## 2. 카링의 반응

| 상황 | 카링 모습 | 말 (예) |
|---|---|---|
| 공기압 부족 | 걸을 때 한쪽으로 기우뚱 절뚝거림, 발밑에 작은 바람 빠짐 표시 | "발이 좀 시려요… 타이어 바람이 빠졌대요. 점검해 줄래요?" |
| 연료·배터리 부족 | 배를 감싸고 기운 없이 느릿느릿, 꼬르륵 표시 | "배고파요… 주유소(충전소)에 들러 줄래요?" |
| 엔진오일·차량 이상 | 얼굴이 창백, 땀방울, 가끔 주저앉음, 심장 빛이 약하게 깜빡 | "몸이 아파요… 정비소에서 고쳐 줄래요?" |
| 워셔액 부족 | 눈을 비빔 | "앞이 뿌옇게 보여요. 워셔액을 채워 줄래요?" |

- 상태가 여러 개면 가장 급한 것 하나만 보여준다 (차량 이상 > 공기압 > 연료 > 워셔액).
- 홈 화면 상단에 작은 경고 칩(예: "🛞 공기압 낮음")이 뜨고, 누르면 퀘스트 카드가 열린다.

## 3. 돌봄 퀘스트

- 차량 신호가 이상 상태로 바뀌면 퀘스트가 생긴다: "타이어 공기압 채우기", "주유하기(충전하기)", "엔진오일 점검받기", "워셔액 채우기".
- **완료 판정은 차량 신호로 한다.** 공기압이 정상으로 돌아오면, 연료가 오르면, 오일 상태가 정상이 되면 자동 완료. 버튼으로 "했어요"를 누르는 방식은 쓰지 않는다(거짓 완료 방지).
- 완료하면: 카링이 회복 연출(통통 뛰며 "나았다!") + **친밀도 +15**(퀘스트 종류별로 차등 가능) + 트립카드처럼 "돌봄 카드" 한 장이 남는다.
- 같은 퀘스트는 한 번 완료하면 다시 이상 상태가 될 때까지 생기지 않는다.

## 4. 친밀도와 선물

- 친밀도는 지금처럼 0~100이지만, 돌봄 퀘스트로 크게 오른다. 100을 넘는 만큼은 "마음 포인트"로 쌓는다.
- 마음 포인트가 일정량(예: 100)마다 모이면, 카링이 가끔(주차 직후 확률 30%) 선물 상자를 내민다.
- 선물은 **차량 정비 쿠폰**: 엔진오일 교환 할인, 타이어 점검, 워셔액 보충, 에어컨 필터 교환 등. 아이템 › 사용하기에 보관한다.

## 5. 블루핸즈 연계 — 확인이 필요한 부분

- 실제로 블루핸즈에서 쓰려면 **현대자동차와의 제휴(쿠폰 발급·검증 체계)** 가 있어야 한다. 앱이 임의로 만든 쿠폰은 매장에서 쓸 수 없다.
- 공모전 규정상 제출물에 사실과 다른 내용이 있으면 선정이 취소될 수 있으므로, MVP에서는:
  - 쿠폰 화면에 **"시연용 · 블루핸즈 제휴 시 사용 가능 (예정)"** 으로 표시한다.
  - 쿠폰에는 QR 자리와 유효기간 자리만 두고, 실제 코드는 넣지 않는다.
  - 블루핸즈 로고·상표는 허락 없이 쓰지 않고 글자로만 표기한다.
- PT에서는 "차량 상태 → 카링 반응 → 돌봄 퀘스트 → 정비 쿠폰 → 블루핸즈 방문"을 사업성(정비 매출 연계) 근거로 설명한다.

## 6. MVP 범위 제안

| 넣는 것 | 미루는 것 |
|---|---|
| 공기압·연료/배터리·엔진오일 신호 연결, 카링 반응(절뚝·배고픔·아픔) | 워셔액, 기타 경고등 |
| 경고 칩 + 퀘스트 카드 + 신호 기반 자동 완료 | 정비 이력 기록, 정비소 길 안내 |
| 친밀도 보상 + 정비 쿠폰 선물(시연용 표시) | 블루핸즈 실제 쿠폰 발급·검증 |
| 개발자 도구에 "공기압 낮춤 / 연료 부족 / 오일 이상" 시험 버튼 | |

## 7. 구현 상태 (2026-11-07)
- 구현: 공기압·연료(전기차는 배터리 20%)·엔진오일 신호 연결, 카링 반응(절뚝·축 처짐·떨림 + 머리 위 표시), 홈 경고 칩, 돌봄 퀘스트 카드, 신호 기반 자동 완료(+20 친밀도), 마음 포인트 40마다 정비 쿠폰 선물(시연용 표시), 사용하기의 쿠폰함, 개발자 도구 시험 버튼.
- 선물은 확률 대신 마음 포인트가 차면 바로 준다(시연에서 확실히 보이도록).
- 권한: 공기압은 `PRIVATE_CAR_SAFETY`, 엔진오일은 `CAR_SAFETY`가 필요하다. 에뮬레이터에서는 둘 다 허용됐지만, 에뮬레이터 차량은 공기압(TIRE_PRESSURE)을 지원하지 않아 실제 값은 받지 못했다. 실차·App Market에서 PRIVATE 권한이 허용되는지 사무국 확인이 필요하다.
